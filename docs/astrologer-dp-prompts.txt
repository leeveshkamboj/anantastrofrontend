ANANTASTRO — ASTROLOGER DISPLAY PICTURE (DP) GENERATION PROMPTS
====================================================================

Source: backend seed data (12 astrologers)

USAGE NOTES
-----------
• Generate ONE astrologer at a time in a fresh chat/session — batch prompts cause same-face drift.
• Production avatars (S3): upload as astrologers/{slug}.jpeg (512×512 JPEG, square headshot)
• Optional local fallbacks: public/images/astrologers/featured/{slug}.jpg or directory/{slug}.png
• Brand palette: yellow #ffc800, purple #2e0a5e, orange #ff9500

CRITICAL — AVOID SAME FACE (read before every generation)
-----------------------------------------------------------
Add this block to EVERY prompt you paste into an image generator:

  UNIQUE PERSON — must look like a completely different real human from all other astrologers in this list.
  NOT a generic AI face. NOT a Bollywood stock model. NOT the same person with different clothes.
  Distinct face shape, nose, jawline, eye spacing, skin tone, age, hair, and accessories as specified below.

Tips that help:
• Use a different AI seed / new conversation per image
• If faces still match, add: "photograph of a specific individual, asymmetric natural features, visible pores, slight imperfections"
• If using Midjourney: add --seed with a random number per slug, or use --cref only for style NOT face
• Reject and regenerate if two outputs could be siblings — they should look like strangers
